# Sentiment-Analysis
A simple web-based Sentiment Analysis application using Python, Flask, and TextBlob to classify text as positive, negative, or neutral. Displays polarity scores and highlights positive and negative words using NLP techniques.
# Sentiment Analyzer

A small Flask + TextBlob web app that classifies text as positive, negative or neutral, shows a polarity score (-1 to +1), and marks the words that drove the result.

## Run it

```bash
# 1. (optional) create a virtual environment
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# 2. install dependencies
pip install -r requirements.txt

# 3. start the server
python app.py
```

Open http://127.0.0.1:5000 in your browser.

TextBlob's default analyzer ships with its own word list, so no extra corpus download is needed.

## API

`POST /analyze`

Request:

```json
{ "text": "The food was great but the service was slow." }
```

Response:

```json
{
  "sentiment": "positive",
  "polarity": 0.2,
  "subjectivity": 0.6,
  "positive_words": ["great"],
  "negative_words": ["slow"]
}
```

Errors return `{ "error": "..." }` with status 400 (empty or invalid input) or 500 (server error).

## Notes

- Polarity between -0.05 and +0.05 is labelled neutral. Change `NEUTRAL_BAND` in `app.py` to adjust.
- Input is limited to 5000 characters (`MAX_CHARS` in `app.py`).
